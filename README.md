# 🪐 OrbiKint — White-Label AI Command Center & Automation Hub

**OrbiKint** (developed under **KintSurge**) is a next-generation, privacy-first AI Command Center and Progressive Web App (PWA) designed to unify local PC control, cloud storage, and workflow automation into a single visual dashboard.

Unlike traditional cloud-locked AI wrappers, OrbiKint keeps client data 100% isolated—storing only authentication and white-label branding centrally while connecting directly to user-owned drives, local agents, and automation engines.

---

### ✨ Key Features

* **🌐 Dynamic Orbital Hub (Live Visualization):** Interactive radial network view that highlights connected drives and tools (Google Drive, Microsoft OneDrive, Local PC, n8n, Supabase) with real-time execution pulses.
* **🛡️ Zero-Data-Lock Privacy Architecture:** Client files, chat logs, and OAuth tokens stay strictly on the client's browser, personal cloud, or local machine.
* **🤖 Hybrid Local + Cloud Engine:** Seamlessly bridges local AI agents (**Hermes**) and local **Docker n8n** instances with 24/7 cloud webhooks (**Render n8n**).
* **🎙️ Voice Control & Speaker Biometrics:** Hands-free voice interaction with speaker verification lock, natural neural TTS voices, and an optional English Speaking Coach mode.
* **📊 Triple-Mode Reporting Engine:** View task outcomes as clean action summaries, interactive charts/graphs, or export them as one-click **White-Label A4 PDF Reports**.
* **🎨 Full White-Label Customization:** Clients can customize their dashboard name, logo, theme colors, and AI assistant persona directly from settings.

---

### 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS, JavaScript / React (PWA + TWA Ready)
* **Auth & Branding Registry:** Supabase (Row-Level Security)
* **Local Agent & Automation:** Hermes Agent, Docker n8n, Tailscale
* **Multi-Model AI Fallback:** Google Gemini, NVIDIA NIM, Groq, Cerebras
* **Reporting & Voice:** Chart.js, jsPDF / html2pdf, Web Speech API & Edge Neural TTS
